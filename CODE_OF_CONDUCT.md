# Code of Conduct

## Our Standard

This project aims to maintain a respectful, constructive, and technically focused collaboration environment.

Examples of behavior that contribute to a positive environment include:

- Being respectful in disagreements
- Giving actionable, evidence-based feedback
- Assuming good intent while discussing technical tradeoffs
- Focusing issues and pull requests on the work, not the person

Examples of unacceptable behavior include:

- Harassment, abuse, or personal attacks
- Discriminatory or exclusionary language
- Deliberate disruption of project discussions or review processes
- Publishing private information without permission

## Scope

This Code of Conduct applies within project spaces, including issues, pull requests, review discussions, and other project-related communications.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.

## Reporting

If you need to report a problem, open a private security report if it involves a vulnerability. Otherwise, contact the maintainers through the repository's available contact path.
